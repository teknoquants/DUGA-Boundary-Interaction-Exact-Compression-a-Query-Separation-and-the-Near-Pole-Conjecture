DUGA Boundary Interaction — white paper and author validation scripts

  DUGA_Boundary_Interaction_whitepaper.docx  — the paper (exec summary, intro, Thm 1, Thm 2,
                                               near-pole Props 1-3, natural-continuation, bibliography)
  validate_boundary.py            — exact rational tests of Theorem 1 (standard library)
  validate_quantum_candidate.py   — numerical diagnostics for the boundary-query problem (NumPy)
  validate_near_pole.py           — near-pole diagnostics for the propositions (NumPy)

Author-supplied scripts, tested against all mathematical artifacts of both source papers.
Finite checks support the proved propositions; they do not test Conjecture 3, any universal
query bound, or originality.
